About Automation With Rohit

A realistic practice application for learning UI and API test automation.

This site was built for students learning test automation with Rohit Sinha. Every page is designed to look and behave like a real product, while keeping locators simple and predictable so you can focus on learning the tool.

All elements are standard HTML, so the same page can be automated with Selenium (Java, Python, C#), Cypress, Playwright, WebdriverIO or Robot Framework. The REST API can be tested with Postman, Rest Assured, Playwright APIRequestContext or Python requests.

What you can practise

  • Locators: id, name, CSS, XPath, text, role, label, test-id
  • Forms, dropdowns, checkboxes, radios, uploads
  • Alerts, frames, tabs and windows
  • Waits, dynamic content and AJAX
  • Web tables, pagination, sorting
  • E-commerce flow: shop, cart, checkout
  • REST API: GET, POST, PUT, PATCH, DELETE

Locator conventions

  • Important elements have a readable id
  • Form fields have a name and a real <label>
  • Key elements have a data-testid
  • Buttons and links have clear visible text
  • Only the "Dynamic Xpath" field changes its id on purpose

Running locally

Install Node.js 18+, open the project folder and run:

node server.js

Then open http://localhost:3000. No other installs needed.
