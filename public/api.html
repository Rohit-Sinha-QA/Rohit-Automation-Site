Quick reference
Status codes you can practise asserting on.

    

      

        
StatusMeaningHow to get it

        
          
200 OKRequest succeededGET /api/users, PUT, PATCH, DELETE

          
201 CreatedNew resource created (see the Location header)POST /api/users, POST /api/orders

          
400 Bad RequestValidation failed or invalid JSONPOST /api/users without email

          
401 UnauthorizedMissing or invalid token / wrong passwordDELETE /api/users/1 without a token

          
403 ForbiddenUser is lockedLogin as locked_user

          
404 Not FoundResource does not existGET /api/users/999

          
405 Method Not AllowedWrong method for a valid pathDELETE /api/products

          
409 ConflictDuplicate email or out of stockPOST /api/users with an existing email

          
5xxServer errors on demandGET /api/status/500, /api/status/503

        
      

      
Data is kept in memory. POST /api/reset (or restarting the server) restores the original 12 users and 12 products.
